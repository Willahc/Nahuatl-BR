# Direitos e licenciamento

`PROJECT_LICENSE_STATUS: OPEN_DECISION`

Nenhuma LICENSE do projeto foi criada. A visibilidade PUBLIC no GitHub não é
uma declaração de licença aberta para código, documentação ou dados originais.
A escolha de licença do conteúdo original será decidida separadamente pelo
responsável humano e registrada em decisão versionada.

Fontes externas mantêm seus próprios direitos e restrições. Work histórica,
Edition moderna, Witness digital, transcrição, tradução e imagem podem ter
condições diferentes. O status de uma Work não se transfere automaticamente
para o recurso digital que a representa.

O GitHub não inclui o PDF C01 nem bytes externos identificados como não
redistribuíveis. `data/source_registry/` registra proveniência e avaliação por
fonte/componente; `manifests/external_sources/` descreve materiais locais
deliberadamente excluídos, sem lhes conceder novas permissões.

C01 tem `redistribution_allowed: false` para o PDF local. Seu manifest não
substitui as restrições específicas da ficha. Não se autoriza download, cópia,
extração ou ingestão pelo simples fato de o caminho esperado estar documentado.

O piloto conserva fragmentos lexicográficos curtos e referências conforme o
escopo previamente aprovado. O hardening não reavalia direitos externos nem
converte os registros jurídicos históricos em parecer jurídico novo. As reservas
das camadas modernas e a revisão editorial permanecem explícitas.
