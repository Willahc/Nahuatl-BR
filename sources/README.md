# Materiais externos locais

Este diretório versiona apenas este README e marcadores `.gitkeep`.
PDFs, áudios, imagens e demais bytes externos ficam fora do GitHub.

C01 é um testemunho local de Hueyapan, inspecionado no Gate 1 e separado do
piloto clássico. Sua presença não autoriza extração ou redistribuição.
O [manifest C01](../manifests/external_sources/C01_hueyapan_2016.yml) registra
caminho esperado, SHA-256 e restrições; o
[source registry](../data/source_registry/C01_hueyapan_2016.yml) mantém a ficha.

Não baixe o PDF para executar os testes: a validação funciona sem ele.
Nenhuma aquisição ou ingestão adicional está autorizada por este documento.
